# Help and editing

```meta
summary: How this wiki works, and how to add to it from a phone or a computer.
```

The game is still being made, and this wiki grows with it. Pages marked **Draft** were written from
early design notes, so names and numbers may still change; pages marked **Stub** are only a start.
Pictures come from the game's current test builds.

Anyone working on the game can add to it, from a phone or a computer, in about two minutes.
