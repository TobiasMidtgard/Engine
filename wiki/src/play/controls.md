# Controls

```meta
summary: Every key in one place: on foot, in a car, in a plane and in a spaceship.
```

{{draft: Keys from the current test builds; they will change as the game grows.}}

## On foot

| Key | Action |
|---|---|
| W A S D | Move |
| Mouse | Look |
| Space | Jump |
| E | Use, talk, get in a vehicle |
| P | In test builds: switch between the free camera and your character |

## Car

| Key | Action |
|---|---|
| W | Throttle |
| S | Brake; hold at a stop to reverse |
| A / D | Steer |
| Space | Handbrake |
| Shift | Boost |
| Mouse | Swing the camera (it settles back behind the car) |
| Wheel | Zoom |
| E | Get out (once stopped) |

## Plane

| Key | Action |
|---|---|
| Mouse | Aim: the plane flies where you look and banks into turns |
| W / S | Throttle lever up and down |
| Shift | Full throttle |
| A / D | Roll; steer on the ground |
| Space | Wheel brakes |
| G | Landing gear |
| Hold C | Look around without steering |

## Spaceship

| Key | Action |
|---|---|
| Space / Ctrl | Lift up and down on the hover engines |
| H | Hover assist: holds the ship up |
| W / S | Main engine lever |
| Shift | Full thrust |
| Mouse | Aim |
| A / D | Roll |
| G | Landing gear |
| J | Cruise: above 12 km, travel between planets and stars |
